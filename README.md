# Asystent ODN

Plik `asystent.js` pobiera zakładka **Asystent ODN** w Szkicowniku Leśniczego i SILPweb.
To skompresowany build – nie edytuj go tutaj; zmiany wychodzą wyłącznie od autora.

Instalacja: zakładka ze strony instalacyjnej otrzymanej od autora (przeciągnij „Asystent ODN” na pasek zakładek).
Wszelkie prawa zastrzeżone.
